## Current research position

The present framework separates three layers:

```text
Retained-state selection
= controlled study of whether retained history changes later selection

Physics-facing extension
= separate falsifiable research route using conventional open-system and information-thermodynamic baselines

Collapse Aware AI™
= separate engineering programme for governed retained-state selection
```

Software behaviour does not validate a universal physical mechanism.

The current physics-facing question is narrower: after conventional system, environment, control and instrument memory are accounted for, does a predeclared history-weighted variable identify an additional reproducible contribution that predicts held-out outcomes and changes appropriately under intervention?

---

## Current evidence sequence

A disciplined progression is:

1. **Formal identifiability** — define the variable, model, null region and analysis so the claim can fail.
2. **Controlled history divergence** — match present conditions while varying history and test held-out directional differences.
3. **Intervention / ablation** — erase, scramble or alter retained state and require the effect to change as predicted.
4. **Metrological convergence** — independent observables support the same timescale and direction.
5. **Independent replication** — another team reproduces the preregistered effect on another system or device.

No lower stage should be presented as if it establishes a higher one.
